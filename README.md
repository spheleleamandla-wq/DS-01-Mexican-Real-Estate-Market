# DS 01: Hands-on Data Science in the Mexican Real Estate Market

## Project Overview
This project focuses on applying hands-on data science techniques to analyze and understand trends in the Mexican real estate market.

## Objectives
- Explore and analyze real estate data from Mexico
- Identify market trends and patterns
- Apply data science methodologies to real-world real estate data
- Develop insights for stakeholders

## Key Areas
- Data collection and cleaning
- Exploratory data analysis (EDA)
- Statistical analysis
- Data visualization
- Market insights and recommendations

## Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebooks

## Project Structure
```
DS-01-Mexican-Real-Estate-Market/
├── README.md
├── data/
├── notebooks/
├── scripts/
└── results/
```

## Getting Started
1. Clone the repository
2. Install required dependencies
3. Explore the notebooks in the `notebooks/` directory
4. Review the analysis and findings in the `results/` directory
